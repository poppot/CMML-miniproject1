# CMML-miniproject1
This COPASI model file is based on COPASI 4.45. It (miniproject_1.cps) contains the complete reaction system, kinetic parameters, and plot templates for simulating O₂ and CO binding to hemoglobin in the alveolar capillary.
Note: The associations between parameter scan settings and initial concentrations must be manually adjusted according to specific simulation requirements (e.g., different O₂/CO levels, Hb decay, or acute CO poisoning scenarios).
The  COSAPI file can be found in https://github.com/poppot/CMML-miniproject1/blob/main/miniproject_1.cps
